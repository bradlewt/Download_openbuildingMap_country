# Security

Do not commit or post:

- ArcGIS access tokens;
- passwords or API keys;
- signed URLs containing credentials;
- private portal credentials;
- confidential service URLs when organizational policy restricts disclosure; or
- local files containing sensitive data.

For secured ArcGIS Online or ArcGIS Enterprise services, prefer ArcGIS Pro's authenticated portal session rather than embedding credentials in source code.

Before a public organizational release, maintainers should add the organization's approved private vulnerability-reporting contact or enable GitHub Security Advisories.
