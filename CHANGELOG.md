# Changelog

## [0.1.0] - 2026-09-29

### Added

- ISO3-driven OpenBuildingMap country extraction.
- ArcGIS Online / ArcGIS Enterprise FeatureServer ADM0 support.
- Local polygon ADM0 support and Natural Earth fallback.
- Configurable ISO3 field.
- Centroid/center-in-country default plus `clip` and `intersect` modes.
- Human-readable `source_name` while preserving `source_id`.
- File Geodatabase, GeoPackage, and GeoJSON outputs.
- Automatic File Geodatabase and GeoPackage creation.
- Concurrent downloads with atomic partial-file handling and download reuse.
- Check-first geometry QA with conditional repair only when errors exist.
- Explicit overwrite protection.
- Optional diagnostic logging and retained work directory.
- Repository documentation, first-repository guide, and issue templates.
- MIT software license plus separate additional patent grant rider.
